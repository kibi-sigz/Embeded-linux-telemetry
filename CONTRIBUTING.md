# Personal progress workflow

- Open `README.md` and follow the linked phases in order.
- After each session, edit `progress/LEARNING_LOG.md`.
- After passing a checkpoint, tick the relevant item in `progress/TRACKER.md`.
- Commit changes to preserve your progress history, for example:

```bash
git add progress/TRACKER.md progress/LEARNING_LOG.md
git commit -m "Record learning progress"
```

If you use GitHub in a browser, edit the tracker and journal files and commit the changes. Reading a Markdown file does not automatically record progress. Keep private device logs and secrets out of the repository.
