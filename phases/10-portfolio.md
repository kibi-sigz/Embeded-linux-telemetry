## Goal

Package your work as a credible, reproducible engineering project.

## Lesson and practical tasks

### 1. Clean the repository

**Try:** Separate source, sample data, documentation, and tests.

**Task:** Add a `.gitignore`; inspect every file before publishing.

### 2. Write the README

**Try:** Include purpose, architecture, setup, run instructions, sample output, and limitations.

**Task:** A stranger should be able to reproduce the demo.

### 3. Add evidence

**Try:** Include a simple system diagram, tests, and a short demo if available.

**Task:** Remove credentials, private logs, and sensitive device identifiers.

### 4. Review honestly

**Try:** List what works, what is simulated, and what remains incomplete.

**Task:** Do not claim flight-ready or safety-critical reliability without evidence.


## Checkpoint

Can another person reproduce your demo from the README? Is it clear which parts are real hardware and which are simulated?
